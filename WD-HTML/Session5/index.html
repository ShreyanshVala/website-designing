4. Difference Between div and Semantic Tags

A layout built only with div tags is generic and does not tell the browser or assistive technology what each section represents. Semantic HTML5 tags like header, nav, article, and aside provide meaning, making the page easier to understand for screen readers and search engines. This improves accessibility and can help with SEO because crawlers can better identify main content, navigation, and related sections.
