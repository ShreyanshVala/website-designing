Task 5 - Static vs Absolute Position

My Explanation

By default, an HTML element has position: static. A static element follows the normal document layout and does not respond to top, right, bottom or left positioning properties.

When we change an element to position: absolute, it is removed from the normal document flow. It can then be positioned using top, right, bottom and left properties relative to its nearest positioned parent.

A real example is a notification badge in WhatsApp. The notification number can be placed at the top-right corner of an icon using position: absolute while the parent icon container uses position: relative.
