Task 5 - Float vs Flexbox

Floats were originally designed mainly for wrapping text around images, but developers started using them for complete page layouts.

Float-based layouts require techniques like clearfix to prevent parent containers from collapsing.

Flexbox was designed specifically for one-dimensional layouts and makes alignment, spacing and responsive columns much easier.

For example, instead of using float: left and float: right, we can use display: flex on the parent and easily control both columns using gap, justify-content and width.
